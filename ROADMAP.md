# Community roadmap

These are proposals, not features already implemented.

- [ ] Reproducible environment with pinned dependencies
- [ ] Configurable workspace paths instead of `C:\AI-Audio`
- [ ] Installation diagnostics and GPU/CPU capability checks
- [ ] Automated audio alignment and click-grid regression tests
- [ ] Better GUI progress reporting and error messages
- [ ] Packaged Windows release
- [ ] Documented model provenance and licensing review
- [ ] Demo made entirely from original or openly licensed audio

**Scope lock:** The public starting point is exactly **v4.4.1 All Stems**; experimental later versions are excluded.
