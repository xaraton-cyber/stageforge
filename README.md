## What is StageForge?

StageForge helps bands prepare studio recordings for live performance. Separate instruments, keep synths and production effects, and export synchronized tracks for playback systems such as M-Live B.Beat.

## v4.4.1 features

- RoFormer by default, Demucs as an alternative
- Six instrument stems: vocals, drums, bass, guitar, piano and other/synth FX
- BPM analysis and fine calibration
- Constant-tempo phase-locked click, manual downbeat selection and count-in
- 48 kHz / 24-bit WAV export with common alignment
- Windows desktop GUI

## Join the project

## Getting started

The Windows launcher and Python source are being prepared for upload. The project requires Python 3.12, FFmpeg and separately installed separation dependencies/models. Installation documentation will accompany the source.
